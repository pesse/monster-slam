# Boss-Porträts

satzmeister.webp und rambler.webp: je 256 × 256 px, verlustfreies RGBA-WebP mit echter Transparenz, Motiv in 240 × 240 px eingepasst und zentriert (mindestens 8 px Rand).

Verwendung: Boss-Wahl, scenes/ui/boss_choice.tscn; auf dunkelblauem Kartengrund etwa 96–128 px hoch anzeigen.

sources/satzmeister.png und sources/rambler.png sind die unveränderten generierten Rohbilder. sources/prompts.json enthält die verwendeten Prompts. Die leere sources/.gdignore verhindert den Godot-Import der Rohdateien.

Zielordner: assets/ui/bosses/.
