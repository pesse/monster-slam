# Kartenbilder: Access 3 — Düsterer Spätherbst

Grundstil, Ablage und Werkbank: [`README.md`](README.md). Jeder Prompt unten ist vollständig
— den ganzen Block kopieren.

## Thema

Melancholisch und geheimnisvoll, ein wenig unheimlich, aber nicht gruselig. Kahle Bäume mit
den letzten Blättern, Laub auf allen Kacheln, Nebel zwischen den Feldern, Laternen am Weg,
Krähen. Trübe Dämmerung — die Halte bekommen warmes Laternenlicht, damit die Marker sichtbar
bleiben.
