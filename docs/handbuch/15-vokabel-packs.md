# 15. Inhalte: Vokabel-Packs

Das Spiel selbst enthält keine Vokabeln. Sie kommen als **Packs**, die man über
„Inhalte“ auf dem Start-Screen holt. So lassen sich neue oder korrigierte Wörter
nachliefern, ohne das ganze Spiel neu herunterzuladen. „Inhalte“ öffnet ein Fenster über
dem Menü; „✕“ oder **Esc** schließt es.

- Jeder Pack steht mit Namen, Beschreibung, Größe und Zustand in der Liste, zum Beispiel
  „Installiert“, „Nicht installiert“, „Update verfügbar“ oder „Inhalt veraltet“.
- Packs, die etwas Neues bringen, sind vorausgewählt. **„Ausgewählte holen“** lädt sie
  herunter und installiert sie. **„↺ Neu suchen“** fragt noch einmal nach, was es gibt.
- **Manche Packs brauchen einen Zugangscode** („Zugangscode erforderlich“). Den Code
  trägt man in das Feld am Pack ein und drückt „Einlösen“. Mit „Code verwerfen“ wird er
  wieder entfernt. „Zugangscode veraltet“ heißt: es wird ein neuer Code gebraucht.
- **„Programm-Update erforderlich“** heißt: der Pack braucht eine neuere Fassung des
  Spiels ([Kapitel 16](16-updates.md)).
- Stößt die Installation auf Dateien, die schon da sind, erscheint „Vorhandene Dateien
  übernehmen“.
- **Ohne Internet** bleiben installierte Inhalte nutzbar. Nur neue holen geht dann nicht.
- **Schreib-Boss (Cloud):** Hier trägt man den eigenen API-Schlüssel für The Rambler ein
  und sieht, was die Abgaben der letzten 30 Tage ungefähr gekostet haben
  ([Kapitel 22](22-schreib-boss.md)).
- **Zurückgezogene Packs** verschwinden von selbst: Führt die Liste einen installierten Pack
  nicht mehr, entfernt das Spiel ihn beim nächsten Abruf. So ging es dem früheren
  Grundwortschatz-Pack; alle Vokabeln kommen jetzt aus den Büchern.
