# 14. Wörter melden

Ist ein Wort im Spiel falsch oder unklar, kann man es melden, damit es korrigiert wird.

- Das geht **nur mit einem Melde-Token**. Es wird im Reiter „Melden“ der Einstellungen
  eingetragen („Eintragen“) und lässt sich mit „Vergessen“ wieder entfernen. Ohne Token
  gibt es den Knopf zum Melden gar nicht.
- Gemeldet wird in der Vokabel-Auflösung nach einer Welle: **„⚑ Melden“**, einen kurzen
  Kommentar eingeben (zum Beispiel „Wortart falsch“), „Absenden“.
- Übertragen werden nur: das gemeldete Wort, dein Kommentar, die Spielversion und der
  Name, der im Token steht. Kein Profilname und keine Fortschrittsdaten.
- **Die Meldung wird zuerst auf dem Rechner gespeichert und danach gesendet.** Klappt das
  Senden nicht (zum Beispiel ohne Internet), steht dort „⚑ Gemerkt — Versand später“.
  Die Meldung geht dann beim nächsten Start mit.
- Im Reiter „Melden“ steht die Liste deiner Meldungen: „✔“ heißt angekommen, „⚑“ heißt
  noch offen.
